# Onyx Detail

Página web de **Onyx Detail**, detailing automotriz en Medellín.

## Estructura

```
index.html       Página principal
css/styles.css   Estilos (colores y fuentes en :root)
js/main.js       Configuración del negocio y cotizador
img/             Fotos (por ahora de referencia, de Pexels)
```

## Cómo verla

Abre `index.html` en el navegador, o usa la extensión **Live Server** en VS Code
(clic derecho sobre `index.html` → *Open with Live Server*).

## Configuración rápida

En `js/main.js`, al inicio:

- `NEGOCIO.whatsapp`: número de WhatsApp con indicativo (ej. `573001234567`)
- `PRECIOS`: tipos de vehículo, paquetes (precio fijo por vehículo) y adicionales
